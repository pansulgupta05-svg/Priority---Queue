Step-by-step Explanation
A Max Heap ensures parent priority ≥ child priority. The root always holds the maximum priority element. Insert adds at the end then sifts up; Extract removes the root and sifts down.
Index Formulas (array-based heap)
Parent of node i     →  ⌊(i − 1) / 2⌋
Left child of i      →  2i + 1
Right child of i     →  2i + 2
Root always at       →  index 0
